Pixel sprites from JSON

Describe a creature as 3D primitives hung on a skeleton, in plain JSON. One Python script poses it, ray-casts it from eight angles, and snaps every pixel to a fixed palette. No hand painting, no Blender.

How it works

  1. JSONBones with offsets, boxes and ellipsoids attached to bones, a palette, and animation channels.
  2. PoseEach channel is a sine, cosine, abs or relu wave on one axis. Sample it at frame t/N and walk the bone tree.
  3. Ray-castAn orthographic ray per pixel finds the nearest shape. The camera yaws 0°, 45°, … 315° for the 8 directions.
  4. QuantiseLambert lighting picks one of four tones from the shape's colour ramp. Silhouettes get an outline colour.

The format

A character file has six keys. This is the fox, trimmed.

{
  "render":   { "size": 72, "scale": 32, "pitch": 22, "pivot": [0, 0.32, -0.12] },
  "palette":  { "outline": "1c0f12", "fur0": "7a2e12", "fur1": "b8501c", "fur2": "e8782a", "fur3": "f5a54a", ... },
  "materials":{ "fur": ["fur0", "fur1", "fur2", "fur3"], ... },
  "skeleton": [ { "name": "body", "parent": null,   "offset": [0, 0.45, 0] },
                { "name": "head", "parent": "body", "offset": [0, 0.1, 0.36] }, ... ],
  "shapes":   [ { "bone": "body", "type": "ellipsoid", "center": [0, 0, 0],
                  "size": [0.32, 0.32, 0.78], "mat": "fur" }, ... ],
  "animations": { "walk": { "frames": 8, "bones": {
      "head": [ { "axis": "y", "wave": "sin", "amp": -6, "phase": 0.1 } ],
      "flo_R": [ { "axis": "x", "base": 4, "wave": "relu", "amp": 45, "phase": 0.45 } ] } } }
}

Palette size is the only colour budget: each run prints how many palette colours the sprites used and checks that no other colour appears.

Run it

pip install numpy pillow
python3 render.py characters/fox.json --out output/fox
# writes output/fox/walk_sheet.png and output/fox/walk_8dir.gif
